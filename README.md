# Brisa

Primera versión funcional de la app de playas de Asturias.

- Pantalla de selección de playa.
- Ficha directa con condiciones de demostración.
- Enlace externo a la fuente original de webcam para las playas que la tienen.

Los valores meteorológicos actuales son de ejemplo. Antes de publicar, conecta una fuente de previsión y configura enlaces individuales y autorizados para cada webcam.
