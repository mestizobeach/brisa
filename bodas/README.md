# ALBOR · Bodas en Asturias

Primera versión de una guía independiente para descubrir espacios y profesionales de bodas en Asturias. Incluye búsqueda, filtros por categoría y zona, favoritos y una lista de planificación. Los favoritos y pasos se guardan localmente en el navegador; no hay cuentas ni reservas.

## Abrir la app

Abre `index.html` en un navegador. También puede publicarse directamente con GitHub Pages desde la raíz de la rama `main`. Todas las rutas de archivos son relativas, por lo que funciona bajo un subdirectorio como `/albor/`.

## Datos

Las fichas iniciales enlazan a las webs oficiales de los negocios. No se muestran precios, disponibilidad ni opiniones sin confirmación. La selección es inicial y no pretende incluir todavía todos los proveedores de Asturias. Los textos y enlaces están en `app.js` para facilitar su actualización.

## Tecnología

HTML, CSS y JavaScript sin dependencias de compilación. El diseño es adaptable a móvil y escritorio.
